# Reports

Reference outputs kept under version control so results can be inspected
without running anything. Every folder is regenerated by one command.

| folder | contents | command |
|--------|----------|---------|
| `data_analysis/` | preprocessing audit, network statistics, overlaps between maps, triangle vs square closure, top hubs | `python src/data_analysis.py` |
| `hi-iii/` | full pipeline on the HI-III human interactome: metrics, figures, permutation importance, top 100 novel predictions with gene symbols | `python src/model.py --dataset hi-iii --output-dir reports/hi-iii` |
| `benchmark/` | ROC-AUC and average precision for every model and heuristic on four interactomes, with uniform and local negatives | `python src/benchmark.py` |
| `synthetic_sample/` | pipeline on the bundled synthetic network (sanity check) | `python src/model.py --input data/raw/sample_ppi_edges.tsv --output-dir reports/synthetic_sample` |

Each pipeline folder contains:

| file | contents |
|------|----------|
| `metrics.csv` | held-out metrics for every model and heuristic baseline, plus cross-validation scores |
| `feature_importance.csv` | permutation importance of each feature for the best model |
| `novel_predictions.csv` | top unobserved protein pairs ranked by the best model |
| `run_summary.json` | configuration, network statistics, split sizes and all metrics |
| `figures/` | ROC and precision-recall curves, confusion matrix, feature importance |

`predictions.csv` (per-pair test scores) and `models/` (fitted classifiers)
are also written by each run but are git-ignored.
