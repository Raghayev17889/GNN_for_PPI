# Graph-Based Protein-Protein Interaction (PPI) Prediction

A modular Python pipeline for modelling protein-protein interaction networks and
predicting missing interactions from network topology.

> Work in progress: the project layout is in place and the modules are being
> implemented.

## Planned layout

```
├── data/          # Raw and processed PPI network data
├── notebooks/     # Exploratory analysis and visualisation
├── src/           # Source code modules
└── requirements.txt
```
