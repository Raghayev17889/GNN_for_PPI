## Real human interactomes

The project's main input is real human protein interaction data. The files come from the
[L3 repository](https://github.com/kpisti/L3) of Kovács et al. (2019), which publishes
several interactome maps as Entrez gene ID edge lists. Gene symbols and gene types come
from an NCBI Entrez Gene snapshot ([dhimmel/entrez-gene](https://github.com/dhimmel/entrez-gene), CC0).
Every URL is pinned to a commit and every file is verified by SHA-256 (see `src/datasets.py`).

| name | type | proteins / interactions (processed) | source |
|------|------|------------------------------------:|--------|
| `hi-iii` | binary (Y2H) | 5,216 / 22,195 | HI-III, CCSB systematic screen (published as HuRI, Luck et al., *Nature* 2020) |
| `hi-ii-14` | binary (Y2H) | 3,985 / 12,883 | HI-II-14 (Rolland et al., *Cell* 2014) |
| `lit-bm-13` | binary (literature) | 4,909 / 9,865 | Lit-BM-13 (Rolland et al., *Cell* 2014) |
| `bioplex-2` | co-complex (AP-MS) | 10,801 / 55,862 | BioPlex 2.0 (Huttlin et al., *Nature* 2017) |
| `biogrid` | mixed | 15,284 / 183,397 | BioGRID human physical interactions |
| `genes-human` | annotation | – | NCBI Entrez Gene (2016 snapshot) |

```bash
python src/datasets.py list                     # what is available
python src/datasets.py download --all           # data/external/, checksum-verified
python src/preprocessing.py --all               # data/processed/<name>.tsv + <name>.report.json
python src/data_analysis.py                     # reports/data_analysis/
```

You can usually skip the first two commands: `python src/model.py --dataset <name>`
downloads and preprocesses a dataset the first time it is used.

### Raw format

The files are header-less, tab-separated `entrez_a  entrez_b  1` triples, mostly with
classic-Mac `\r` line endings. `src/graph_builder.read_edge_table` detects the missing
header and handles any line-ending convention.

### Preprocessing

`src/preprocessing.py` cleans each network step by step and records how many
interactions and proteins every step removes (`data/processed/<name>.report.json`):

1. drop rows with missing identifiers;
2. optional confidence threshold (`--min-score`);
3. remove self-interactions (homodimers: 322 in HI-III, 890 in Lit-BM-13);
4. collapse duplicate and reversed pairs;
5. drop identifiers missing from the gene annotation (discontinued Entrez IDs);
6. keep interactions between protein-coding genes only (removes ORFs mapped to ncRNA and pseudogene loci);
7. keep the largest connected component.

The processed TSV has the columns `protein_a`, `protein_b`, `weight`, `symbol_a` and `symbol_b`.

The interaction data belongs to its original authors. Please cite the original
publications (see the table above and the README) when using them.

## Other real data

**STRING** (<https://string-db.org/cgi/download>): download
`<taxon>.protein.links.v12.0.txt.gz` for your organism (e.g. `9606` for human).
The format is detected automatically; `--min-score 700` keeps STRING's high-confidence set:

```bash
python src/preprocessing.py --input data/external/9606.protein.links.v12.0.txt.gz --name string-human \
    --min-score 700 --no-annotation
python src/model.py --input data/processed/string-human.tsv --betweenness-samples 500
```

**BioGRID / IntAct / HuRI exports**: reduce the export to a table of interactor
identifiers (optionally with a numeric confidence column) saved as `.tsv` or `.csv`.
Pass it to `src/preprocessing.py --input` (with `--no-annotation` if the identifiers
are not Entrez gene IDs) or directly to `src/model.py --input`.

## Bundled synthetic sample: `raw/sample_ppi_edges.tsv`

A **synthetic** PPI network (2,000 proteins, 7,518 interactions) generated by
[`generate_synthetic_ppi.py`](generate_synthetic_ppi.py) with the
duplication-divergence model of PPI evolution. It ships with the repository so
the tests and a quick demo run without downloads.

| column      | description                                                         |
|-------------|---------------------------------------------------------------------|
| `protein_a` | first interactor (synthetic identifier, e.g. `P00977`)              |
| `protein_b` | second interactor                                                   |
| `score`     | confidence score on STRING's 0-1000 scale                           |
| `source`    | `biological` (grown by the model) or `noise` (spurious screen hit)  |

The `source` column is ground truth that real data would not have. The pipeline
ignores it and reads only the first three columns.

```bash
python src/model.py --input data/raw/sample_ppi_edges.tsv     # demo run
python data/generate_synthetic_ppi.py --n-proteins 5000 --seed 7 \
    --output data/raw/synthetic_ppi_5k.tsv                    # larger variant
```

Results on the synthetic network demonstrate the method; they are not biological findings.
