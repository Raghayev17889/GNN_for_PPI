# Data

## Bundled sample: `raw/sample_ppi_edges.tsv`

A **synthetic** PPI network (2,000 proteins, 7,518 interactions) generated by
[`generate_synthetic_ppi.py`](generate_synthetic_ppi.py) with the
duplication-divergence model of PPI evolution. It ships with the repository so
the pipeline runs out of the box, without downloads.

| column      | description                                                         |
|-------------|---------------------------------------------------------------------|
| `protein_a` | first interactor (synthetic identifier, e.g. `P00977`)              |
| `protein_b` | second interactor                                                   |
| `score`     | confidence score on STRING's 0-1000 scale                           |
| `source`    | `biological` (grown by the model) or `noise` (spurious screen hit)  |

The `source` column is ground truth that would not exist for real data; the
pipeline ignores it (only the first three columns are read). It is kept so you
can check, for example, how a score threshold trades biological edges against
noise.

Regenerate it, or create larger variants, with:

```bash
python data/generate_synthetic_ppi.py                        # default sample
python data/generate_synthetic_ppi.py --n-proteins 5000 --seed 7 \
    --output data/raw/synthetic_ppi_5k.tsv
```

Because the network is synthetic, results obtained on it demonstrate the
method; they are not biological findings.

## Using real interaction data

Real networks go in `data/external/` (git-ignored, as these files are large).

**STRING** (<https://string-db.org/cgi/download>): download
`<taxon>.protein.links.v12.0.txt.gz` for your organism (e.g. `4932` for
*S. cerevisiae*, `9606` for human). The format is detected automatically;
use `--min-score 700` for STRING's high-confidence set:

```bash
python src/model.py --input data/external/4932.protein.links.v12.0.txt.gz --min-score 700
```

**BioGRID / IntAct / HuRI**: reduce the export to a two-column table of
interactor identifiers (optionally with a numeric confidence column) saved as
`.tsv` or `.csv`, then pass it with `--input`. Column names can be given with
`--source-col`, `--target-col` and `--weight-col`.
